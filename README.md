# Connectas website

Public site for Connectas Enterprises LLC (connectasconsulting.com), in English (root) and Portuguese (/pt).
Astro, static pages. Same visual identity as the Connectas Wix Studio design: Poppins ExtraLight, black & white,
network motif. Publishing goes through Wix Headless — see `SETUP.md`.

```bash
npm install
npm run dev      # http://localhost:4330
npm run build    # static build into dist/
```
